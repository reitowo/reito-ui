# 介绍

Reito UI 是一套面向桌面工具的 React 组件库。它以 Graphite 中性灰阶为基础，提供紧凑的控件、清晰的阅读面和克制的边界，让表单、设置、数据视图与 AI 工作面说同一种设计语言。

组件建立在固定版本的 shadcn / Base UI（base-nova）原语之上，保留 Base UI 的键盘行为与无障碍语义；颜色、间距、字号、圆角与动效全部来自 `@reito/tokens` 生成的设计变量。

## 三层组件

| 层 | 入口 | 适合 |
| --- | --- | --- |
| 基础 | `@reito/ui/basic` | 按钮、表单输入、选择、导航、反馈、页面积木（Page、Panel、Stack、Inline、Grid、Text、Heading） |
| 复杂 | `@reito/ui/complex` | 数据表格、树与层级选择、表单管理、富文本、设置、工作区外壳与搜索 |
| AI | `@reito/ui/ai` | Composer、消息与结构化 parts、工具调用、上下文、权限、产物与任务流 |

依赖方向固定为基础 → 复杂 / AI：基础层不依赖业务层。根入口 `@reito/ui` 同时导出三层 API，子入口便于表达依赖层次。

## 设计原则

- **工作是主角。** 正在进行的任务占据主要视觉面；侧栏是轻量行，工具栏短小，检查器和产物预览按需打开。
- **边界柔和，焦点明确。** 普通分隔使用低对比边界，键盘焦点始终清晰可见。
- **主题是代码。** 一个根 `ReitoThemeProvider` 定义全局主题，嵌套 Provider 定义局部作用域，不靠页面 CSS 覆盖。
- **默认紧凑。** compact 是默认密度；密度是样式能力，不是产品界面上的开关。
- **原创外观。** 参考了 Cursor 与 Claude Desktop 的工作面结构，但 tokens、样式与文案均为本库原创，不包含任何专有字体或品牌素材。

## AI 组件不连接模型

AI 层只提供界面与本地状态。请求、停止、授权执行、上传和模型调用由你的应用实现；站内所有对话与工具调用示例都是本地演示，不代表真实的 AI 响应或外部集成。
