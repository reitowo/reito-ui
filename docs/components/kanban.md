# Kanban 工作面范围（APP-KANBAN-01）

个人任务工作台，提供多列卡片、同列排序与跨列移动。原创 React 组合复用本库 Button/Input 和 SortableList 的稳定身份及键盘操作约定；使用浏览器原生拖放，并提供完整键盘等价入口。

cards 保存标题/描述与禁用状态，columns 保存有序 cardIds；每张卡片只能属于一列，重复或悬空引用显式拒绝。移动使用目标列和 beforeId 稳定锚点，搜索仅影响显示，不创建另一份排序，隐藏卡片的相对顺序保持。

宿主受控 columns 和异步 onMove 接受完整候选列及移动详情。保存期间禁用重复移动；失败保持原列与卡片位置，提供重试和反馈。筛选、加载、空、禁用列/卡片、只读、键盘焦点保持与窄屏均须有 Story 和验证。该看板不复用 TaskQueue 的执行状态模型，也不连接外部任务服务。

0.5.8 发布范围包含此组件。Controls、鼠标和键盘移动、过滤顺序、保存失败/重试、主题密度、焦点及构建检查的实际结果见 [发布验证](../validation-release-058.md)。
