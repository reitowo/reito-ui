# Reito UI 0.5.7

发布日期：2026-10-11。

本版统一主题菜单与密度设置，完善设计变量检查器，并修复控件的圆角、间距和编辑器对齐。沿用已发布的 138 个组件族；主工作区中的 Kanban 新组件草稿继续保留，不属于本版。

- Lab 首页、总览、组件详情和配色示例使用同一主题菜单，密度选择并入其中并持久化。
- 舒适控件收敛为 28 / 32 / 36 / 40px，比紧凑增加一级 4px；内容间距、菜单行、表格单元格和面板内距随共享 token 协调调整。
- 设计变量面板提供分类、搜索、当前模式筛选、实时 CSS 值、来源详情和完整 JSON 导出。新入口 `@reito/tokens/catalog` 从同一源定义和编译器生成元数据。重复名称只显示一次，颜色预览放在行末。
- RichTextEditor 使用安静的焦点边界，任务复选框与文本首行对齐。
- ColorPicker 色块保持圆角矩形，InputTags 内部标签与外框圆角协调，Breadcrumb 使用相关内容间距。
- 总览去掉多余的顶部确认面板和英文副标题；组件加载过程中不再显示跳动的加载文案。

变量目录含 907 条源定义，包括主题/密度变体和配色方案，不能等同于 907 个独立 CSS 变量。组件专用 token 目前覆盖 Button、Input、Menu、Card、ScrollArea；其他组件仍复用基础及语义角色。实时值对应当前根作用域。

```sh
npm install @reito/ui@0.5.7 @reito/tokens@0.5.7
```

默认视觉调整应在消费应用中检查。发布构建、静态检查、交互回归和包契约的实际结果见 validation-release-057.md；每项视觉参考及测量记录保留在对应验证文档中。
