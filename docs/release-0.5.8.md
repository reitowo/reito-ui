# Reito UI 0.5.8

发布日期：2026-10-17。

新增 Kanban 看板组件，提供多列卡片、同列排序、跨列移动、搜索和受控保存。组件目录增至 139 个组件族（基础 72、复杂 43、AI 24）。

- 支持原生拖拽、Alt + 方向键，以及点击卡片后的移动操作；移动后保留键盘焦点。
- 以稳定卡片 id 和 beforeId 锚点移动；筛选不会丢弃隐藏卡片或打乱其相对顺序。
- 异步保存期间阻止重复操作，失败保留原位置并提供重试。宿主持有 columns 和持久化逻辑。
- Storybook 提供参数调试、只读、加载、空内容和保存失败示例；沿用共享主题和密度 tokens。
- 同时包含 0.5.7 发布后的测试修复：协调 Storybook 自动无障碍扫描与手动扫描，真实违规和非竞争错误仍会使测试失败。

安装：

```sh
npm install @reito/ui@0.5.8 @reito/tokens@0.5.8
```

从 `@reito/ui/complex` 导入 `Kanban` 及其 props / 数据类型。它不连接外部任务服务。实际构建、检查、交互与发布验证见 [验证记录](validation-release-058.md)。
