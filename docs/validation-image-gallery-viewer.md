# ImageGallery 高级查看器验收

日期：2026-09-07

## 范围

GALLERY-02 在 GALLERY-01 的受控图片集合上增加查看器操作：有界缩放、放大后拖动定位、90° 旋转、水平/垂直翻转、浏览器全屏状态和显式下载回调。切换图片或关闭查看层会统一复位变换；关闭时也会退出由组件打开的全屏。

## 自动验证

- `npx playwright test tests/image-gallery.spec.ts tests/image-gallery-viewer.spec.ts --workers=1`：26 项通过，其中 13 项为高级查看器，13 项为基础画廊回归。
- 高级测试覆盖缩放步长与上下界、键盘缩放/复位、旋转/翻转、指针拖动、切图/关闭复位、焦点恢复、当前项下载回调、隐藏工具栏和浏览器 Fullscreen API 状态。
- 深色/浅色主题 × 紧凑/舒适密度均执行可访问性与 760 × 680 视口截图检查。
- Storybook 本族 13 个 Story × 4 组主题密度，共 52 次组合审计通过。
- `npm run check` 与 `npm run build` 通过；生产构建仅保留既有的 chunk size 提示。

## 视觉检查

检查 `viewer-tools` 的深色/紧凑与浅色/舒适截图。查看工具保持单行、图像舞台占主要空间，底部导航在两种密度下不被挤压；Dialog 边界、遮罩和焦点环沿用 Graphite tokens。与 PrimeVue Galleria / Image 仅对照交互能力，Reito UI 仍使用紧凑桌面工作区布局、自己的图标顺序和宿主回调边界。

## 支持边界

组件不下载文件、不推断文件名、不处理鉴权或资源缓存。浏览器拒绝全屏时保持非全屏状态。拖动定位只在比例大于 100% 时启用；缩放回到 100% 或以下会清除位移。
