# Color palette provenance

The optional named color scales (50–950) are derived from Tailwind CSS 4.3.3, converted from OKLCH to clipped sRGB for this package's DTCG color contract. Graphite's original palette and semantic roles remain original to Reito UI. Runtime theme mappings are defined by Reito UI.

Source: https://github.com/tailwindlabs/tailwindcss
